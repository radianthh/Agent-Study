2025 AI Agent 주요 트렌드

  • Agentic RAG: 자율적 에이전트가 메모리, 추론 능력을 이용해 복잡한 작업을 수행하며, 계획 및 실행을 돕는 AI입니다. 특히 정보 검색과 관련된 워크플로우에 적용됩니다. 참고 링크
  • Multi-Agent Systems (MAS): 복잡한 문제를 해결하기 위해 특화된 에이전트 팀을 구축하는 시스템입니다. 참고 링크
  • Human as "Agent Boss": 인간의 역할이 '실행자'에서 '감독자'로 변화하면서 AI가 더 많은 업무를 자율적으로 수행하게 됩니다. 참고 링크
  • Voice Agents: 음성 에이전트가 단순한 대화를 넘어서는 컨텍스트와 뉘앙스를 이해합니다. 참고 링크
  • AI Agent Protocols: AI 간의 소통을 가능하게 하는 프로토콜로, A2A, ACP, SLIM 등이 있으며 다양한 회사에서 채택되고 있습니다.
